## 1. About this policy

This Privacy Policy explains how Daisy ("Daisy," "we," "us," or "our") handles information when people use the Daisy Discord application or any associated Daisy service that links to this policy. Daisy is an independent application and is not operated by Discord.

Features described below apply only when they have actually been enabled. This policy does not mean that every feature is available in every Discord server.

## 2. Information Daisy may process

### Information provided by Discord

Depending on the features used, Daisy may receive and process:

- Discord user IDs, usernames, display names, and profile information needed to identify users and display bot responses.
- Discord server (guild) IDs, server names, channel IDs, and relevant permission information needed to configure and operate server features.
- Application-command submissions, button interactions, modal submissions, and preferences such as language or notification settings.
- Member join, leave, or update event data **only if a feature that requires Guild Members Intent is actually enabled**.
- Message text and associated message fields **only when an actual feature requires Message Content access and the bot is permitted to receive that information**. Access to a message is not the same as retaining it; see Section 4.

### Information created through Daisy features

Where supported and used, Daisy may process records such as:

- Server or bot listing submissions, descriptions, tags, and application review decisions.
- Voting activity and vote cooldowns.
- Virtual Coins, XP, levels, achievements, inventory, purchases, and transaction histories.
- Server treasury contributions, community goals, and related authorizations.
- User support requests, reports, and abuse-prevention events.

These records are described as possible feature data; the operator must ensure this list reflects what the deployed application actually uses.

### Technical information

Daisy may generate limited operational records, such as interaction identifiers, timestamps, error codes, and security logs, to operate and protect the service. Technical records should be limited to what is necessary.

## 3. Why we use information

We use information, as applicable, to:

1. Respond to Discord interactions and provide requested features.
2. Configure and manage community features selected by server administrators.
3. Maintain voting, reward, virtual economy, and other user-facing records when those features are enabled.
4. Detect duplicate requests, prevent abuse, investigate security incidents, and enforce applicable rules.
5. Diagnose errors, maintain service reliability, and respond to support requests.
6. Comply with applicable laws and Discord's Developer Terms and Policies.

We do not require users to provide their Discord password or account credentials.
