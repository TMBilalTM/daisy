## 1. Scope

This Privacy Policy describes how the independent Discord application **Daisy** processes information when users interact with the bot or related Daisy services. Daisy is not operated by Discord. Features that are still in development are not treated as currently active services.

## 2. Information processed

Daisy may process the following information where necessary for features that are actually enabled:

- **Account and server data:** Discord user IDs, usernames, server IDs, channel IDs, relevant permissions, and configuration settings.
- **Interaction data:** slash-command parameters, button or menu selections, modal submissions, settings, and timestamps.
- **Community features:** server listing submissions, votes, cooldowns, virtual Coins, XP, missions, achievements, and transaction history **only for features already deployed and enabled**.
- **Membership events:** member join, leave, or update information **only if Daisy actually operates a feature requiring Guild Members Intent**.
- **Message content:** ordinary channel messages or related message information **only if Daisy actually operates a feature requiring Message Content Intent**.
- **Operational data:** limited error logs, request IDs, and security-related events necessary to operate the service.
